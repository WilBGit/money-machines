Technical Levels Quick Reference

RSI Zones

RSI Level Zone Meaning Action
0–20 Deeply Oversold Extreme selling exhaustion Look for call entries
20–30 Oversold Selling pressure easing Prepare call setups
30–45 Weak Bearish Mild downtrend Wait for reversal signal
45–55 Neutral No clear direction Avoid directional trades
55–70 Weak Bullish Mild uptrend Wait for pullback entry
70–80 Overbought Buying pressure stretching Prepare put setups
80–100 Deeply Overbought Extreme buying exhaustion Look for put entries

Tip: RSI divergences (price makes new high/low but RSI doesn't) are the highest-confidence signals.

SMA Quick Guide

SMA Meaning How to Use
20 SMA Short-term trend Price above = short-term bullish; below = bearish
50 SMA Medium-term trend Crosses = trend change; price reclaims it = trend resume
100 SMA Long-term trend Institutional level; strong support/resistance
200 SMA Macro trend The "line in the sand" — above = bull market, below = bear

Key Crossovers: - Golden Cross (50 SMA > 200 SMA) = Bullish long-term signal - Death Cross (50 SMA < 200 SMA) = Bearish long-term signal

ATR (Average True Range) Usage

Use How
Stop placement Set stop 1.5–2× ATR below entry
Target setting Target = 2–3× ATR from entry
Position sizing Larger ATR → fewer contracts (wider stop = more risk $)
Volatility filter ATR expanding = trend strengthening; contracting = ranging

ATR Formula: ATR(14) = average of true range over 14 periods. True Range = max(H−L, |H−prevC|, |L−prevC|)
